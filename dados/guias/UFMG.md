# UFMG

> Resumo simplificado para fins de demonstração. Regras de ingresso mudam todo ano — confira sempre o edital ou o site oficial.

## Formas de ingresso
A UFMG usa o Sisu, com a nota do Enem, como principal forma de ingresso.

## O que pesa
Pesos diferentes por área do Enem conforme o curso. Cursos de saúde e biológicas valorizam Ciências da Natureza.

## Dicas para o candidato
Conferir no termo de adesão ao Sisu os pesos de cada curso antes de se inscrever.
